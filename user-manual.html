Cursora User Manual

Your AI companion, right at your cursor. Select anything, press Ctrl + G, and ask.

1. SelectText in any app, or files in File Explorer.
2. Press Ctrl+GA chat bubble opens at your cursor, with your selection attached.
3. AskThe answer appears as it's written. Ask follow-ups, then press Ctrl + G to close.

Cursora runs quietly in the background, with an icon in the system tray. It works with an AI model on your own computer, or with a cloud AI service using your own API key. You don't copy, paste or switch windows: the bubble comes to you, and it goes away when you're done.

Cursora works on Windows 10 and 11 and on Linux (fully on X11, with a few limits on Wayland; see Linux).

Install

  • Windows: run the .msi or .exe installer. Install for all users (into Program Files) if you want to use Cursora in apps that run as administrator; see General settings.
  • Linux: install the .deb package (Ubuntu and Debian), or make the .AppImage executable and run it (any distribution).

The installers include the built-in engine, so you can run an AI model file on your computer without installing anything else.

First-time setup

The first time Cursora starts, a short setup window opens. A green bar at the top shows how far along you are.

  1. Choose an AI source. Pick a model running on this computer (LM Studio is found automatically), the built-in engine with a .gguf model file, or a cloud provider with your API key. Cursora tests the model before you can go on, so your first question just works. For the built-in engine, you also choose how long the model stays loaded.
  2. Choose a personality. Pick one of the ready-made personas, or turn personality off for the plain model.
  3. Choose your hotkeys. Ctrl + G to ask and Ctrl + Shift + G to snip are set for you; click one and press new keys to change it.
  4. Start with your computer? Leave it ticked to have Cursora ready every time you log in.

Everything you choose here can be changed later in Settings, and you can run setup again from Settings → General → Re-run setup.

Ask about a selection

  1. Select some text in any app: a web page, a document, an email, a PDF, code in your editor, or output in a terminal.
  2. Press Ctrl + G. The bubble opens next to your cursor, showing the app the text came from and the first lines of the text.
  3. Type your question and press Enter. Use Shift + Enter for a new line.
  4. The answer appears as it's written. Ask follow-up questions in the same bubble: Cursora remembers the conversation and the text you selected.
  5. Press Ctrl + G again to close the bubble. You're back where you were, in the same app.
Nothing selected? The bubble opens as a plain chat, so you can ask anything.
Your clipboard is safe. Whatever you copied before is still there after Cursora reads your selection. In terminals, Cursora never presses Ctrl + C, so a running program keeps running.

To ask about something else instead, click the × next to the captured text before your first question. Long selections are cut at 50,000 characters, and the bubble says so.

Ask about files

Select files or folders in File Explorer or on the Desktop, then press Ctrl + G. Each item shows as a chip with its name and size.

  • Text files are read and sent with your question, up to 100 KB each and 300 KB in total. Larger or binary files are described by name, type, size and date only.
  • Folders are listed, up to 50 items each. Cursora doesn't open subfolders.
  • Images (PNG, JPG, WebP, GIF) are attached as pictures when your model can see images, up to 4 at a time.
  • Up to 20 items are used; the bubble tells you how many were left out.

The chat bubble

Header

The persona's name, the personality button, the model (click it to switch to another model), and where the answer comes from: Local, LAN or Cloud.

Move and resize

Drag the bubble by its header. Click the expand button in the header to open the conversation in a larger window you can resize.

Answer actions

Copy copies the answer as Markdown; hold Shift to copy plain text. Regenerate asks again. Save as skill turns your question into a reusable command.

Stop

While an answer is being written, the Send button becomes Stop. The part written so far is kept.

The bubble stays open when you click elsewhere or press Esc, so you can read the answer while you work. Only the ask hotkey closes it.

What will be sent, under the conversation, shows the exact text that will go to the AI, with any hidden personal details marked. See Privacy.

Snip part of the screen

For things you can't select, like an image, a video frame, a scanned page or a chart:

  1. Press Ctrl + Shift + G. The screen dims and the pointer becomes a crosshair.
  2. Drag a box around what you want to ask about. Press Esc to cancel.
  3. The bubble opens with your snip attached. Ask your question.

You can also type /snip in the bubble, or choose Snip an area instead when nothing was selected.

Snipping needs a model that can see images. If your current model can't, Cursora offers another of your models that can, or points you to Settings → Models.

Type / in the bubble to see the list. Use ↑ and ↓ to move, Tab or Enter to choose, and Esc to close the list.

Make your own skills

Create one in Settings → Skills → New, with /new-skill, or with Save as skill under any question you asked. Give it a name like eli5, a short description and its instructions, then use it as /eli5 straight away.

Instructions can use {{input}} (what you type after the command), {{app}} (the app the text came from), {{language}} (your reply language) and {{date}}. Your selection is always attached for you.

Skills are plain Markdown files in the skills folder, so you can share them, edit them in any editor, or duplicate a built-in one to change it. Changes take effect within a second.

Personality

A persona gives your companion a name and a character. Four come ready-made:

PersonaStyle
CursoraFriendly and balanced (the default)
AdaProfessional, detailed answers, for experts
ArjunWitty and brief
SageCalm and patient, for beginners

In Settings → Personality you can create your own: its name, gender, tone, how much it says, whether it uses emoji in answers, its reply language, your level of expertise, and your own instructions. You can also duplicate, import and export personas.

Switch personas from the tray menu, in Settings, or by typing /persona <name>. To use the plain model with no character, turn personality off with the button in the bubble's header, in the tray menu, or in Settings.

AI models

Open Settings → Models to add and choose models.

On your computer

  • LM Studio is found automatically when it's running. Click Use it.
  • Any OpenAI-compatible server (llama.cpp, vLLM, Jan, LocalAI, KoboldCpp and others): add it by its address.
  • The built-in engine: choose Built-in engine as the source and pick a .gguf model file. Cursora suggests a model size that suits your computer's memory.

For the built-in engine, choose how long the model stays loaded:

OptionMeaning
Always onLoaded with Cursora, ready at once. Stays until you stop it or quit.
Off when idleUnloads after some minutes without questions, freeing memory.
Only while answeringLoads for each question and unloads when the bubble closes. Uses the least memory.

In the cloud

Choose a provider (OpenAI, Anthropic, Google Gemini, OpenRouter, Groq, DeepSeek, Mistral, or Custom for any OpenAI-compatible service), paste your API key, and click Add. Then click Choose models and tick the models you want, and pick your Default model at the top.

Your API keys stay safe. Keys are stored only in your system's keychain (Windows Credential Manager, or the Secret Service on Linux), never in a file or a log.
Pick a chat model. Cursora hides models that can't answer in text, such as speech, music, image and embedding models. Free plans don't always include every model: if one says it isn't available, choose another, such as a "flash" or "mini" model.

Click Test connection on any provider to check it works. Providers on another computer in your home or office network (LAN) can be marked as trusted, so they count as local in local-only mode.

Privacy

Cursora has no telemetry, no analytics and no update checks. It only talks to the AI models you set up. Everything below is in Settings → Privacy.

Local-only mode

Turn on Local-only: nothing leaves this computer, and only models on this computer (or on a LAN host you trust) can answer. Cloud models are turned off everywhere. You can also switch it from the tray menu, and the bubble shows Local-only while it's on.

Blocked apps

Cursora reads nothing in blocked apps: no text, no keys, no clipboard. Password managers (KeePass, KeePassXC, 1Password, Bitwarden, Enpass) and Windows credential prompts are blocked from the start. To block the app you're using, choose Block Cursora in <app> from the tray menu, or add a rule in Settings by program name or by a word in the window title.

Hide personal details

Before text goes to a cloud model, Cursora replaces personal details with placeholders such as [EMAIL_1], then puts the real values back into the answer on your computer. It finds email addresses, phone numbers, card numbers, IBANs, API keys, Aadhaar numbers and PAN numbers, and you can add your own patterns. Each kind can be switched on or off, and you can apply it to local models too.

Images are sent as they are. Hiding works on text only. The bubble warns you before an image goes to a cloud model.

Before sending

Turn on Confirm before sending to cloud models and the bubble shows exactly what will be sent and waits for you to press Send.

History

Conversations are saved on your computer only. In Settings → History you can search them, click one to reopen it in a larger window, delete one with its ×, or Clear all.

Choose how long to keep them: 30 days, 90 days (the default), 1 year, or forever. Untick Save conversations on this computer and nothing is written to disk.

The tray menu

Right-click the Cursora icon in the system tray:

Linux

  • X11 works as on Windows. Selected text is read directly, without pressing any keys.
  • The tray icon needs AppIndicator. Ubuntu includes it; on other GNOME systems, install the AppIndicator extension. Without it, everything still works through the hotkey and cursora --settings.
  • Wayland: apps can't listen for hotkeys, so Settings → General shows the command to bind as a custom shortcut in GNOME or KDE. Install the wl-clipboard package so Cursora can read your selection. The bubble opens in the middle of the screen, selected files can't be read, and blocked apps can't be detected.
  • Snip on Wayland: copy part of the screen with your desktop's screenshot tool, then run cursora --snip.
  • API keys need a keychain service (GNOME Keyring or KWallet). Models on your computer work without one.

Troubleshooting

You seeWhat to do
"No AI model is available"Click Open setup and choose a model, or start your local model server.
"The provider rejected the API key"Check or replace the key in Settings → Models.
"The provider is limiting requests right now"Wait a minute, then retry. Free plans allow only a few requests a minute.
"Your account with this provider has no credit left"Add credit on the provider's website, or pick another model.
"This model isn't available from the provider"Pick another model in Settings → Models. Your plan may not include it.
"That's too much text for this model"Remove the captured text, select less, or use a model with a larger context.
"Couldn't reach the provider"Check your internet connection, or that your local model server is running.
"The provider had a problem answering"Retry in a moment. The provider's own message is shown below, if it gave one.
"Local-only mode is on"Pick a local model, or turn local-only mode off.
"Cursora can't read apps running as administrator"Turn on Settings → General → Run as administrator (Windows).
"Cursora is blocked in <app>"That app is in your blocked apps. Remove it in Settings → Privacy if you want to use Cursora there.
The hotkey does nothingCheck Cursora isn't paused (tray menu). If another app already uses the key, Cursora tells you; choose another in Settings → General.

If something else goes wrong, Settings → About has an Open folder button for the logs. Logs never contain your text, questions, answers or keys.
