# Security policy

Cursora reads the text you select in other apps, so security and privacy issues matter a lot to us.

## Reporting a vulnerability
**Please don't open a public issue.** Report it privately instead: on this repository, open the **Security** tab and choose **Report a vulnerability**. We'll reply within a week, keep you updated, and credit you in the fix if you want.

These are the most useful reports:
- user content (selected text, files, screenshots, history) leaving the computer in a way the user didn't choose, for example while local-only mode is on;
- the privacy guard missing personal details before a cloud request;
- an API key reaching a log, a file or the webview, instead of staying in the OS keychain;
- text from a page or an app making Cursora type, click or send something the user didn't ask for;
- the auto-update accepting a file that isn't signed.

## Supported versions
Only the latest release gets security fixes. Cursora updates itself, unless you have turned updates off.
